# DailyClassical

One great work a day, with a listening guide you follow while the music plays.
Native iOS (SwiftUI, Liquid Glass), English and Turkish from v1.

| Folder | What lives there |
| --- | --- |
| `ios/` | SwiftUI app. Project generated by XcodeGen from `ios/project.yml`. |
| `backend/` | API (Node + Hono + Drizzle) deployed on Railway, data in Neon Postgres. |
| `content/` | Source of truth for piece content: one markdown file per piece in `en/pieces/` and `tr/pieces/`, `glossary.md` per language, `composers.yaml`, `paintings.yaml`, `schedule.yaml`, `research/` verification notes. **How to write a piece: [`content/CONTENT_GUIDE.md`](content/CONTENT_GUIDE.md).** |
| `design/` | Claude Design export (`DailyClassical2.html` is the full canvas), `SPEC.md`, the custom SVG icon set. |
| `project-knowledge/` | Product brief and the original launch content. |

## Content pipeline

```
content/<locale>/pieces/*.md + glossary.md ──content:build──▶ content/build/<locale>.json ──db:seed──▶ Neon
                                                         └──fixtures──▶ ios/…/Resources/Fixtures (offline dev + previews)
```

- The catalogue is not only symphonies: each piece has a `form` (symphony, piano-concerto, piano-sonata, string-quartet, …) that drives the Library filter.
- `[[term]]` (EN) and `[[term|yüzey metni]]` (TR) mark glossary terms; the key is always the English term.
- Listening-stop times are stored in seconds per movement of the reference recording; the app formats them per language.
- Every locale falls back to English for anything not yet translated.

## Backend

```bash
cd backend
cp .env.example .env          # Neon pooled + unpooled URLs, JWT secret
npm install
npm run content:build         # parse + validate EN/TR markdown
npm run db:migrate            # apply drizzle/ migrations
npm run db:seed               # load content
npm run dev                   # http://localhost:3100
```

Endpoints (all content endpoints take `?locale=en|tr` or `Accept-Language`):
`GET /v1/today?date=YYYY-MM-DD`, `GET /v1/pieces`, `GET /v1/pieces/:id`, `GET /v1/glossary`, `GET /v1/composers`,
`POST /v1/auth/register` (202, emails a 6-digit code), `POST /v1/auth/verify`, `POST /v1/auth/verify/resend`, `POST /v1/auth/login` (403 `email_not_verified` until confirmed),
`POST /v1/auth/password-reset`, `POST /v1/auth/password-reset/confirm`, `GET /reset-password` (web page),
`GET|DELETE /v1/me`, `GET /v1/favourites`, `PUT|DELETE /v1/favourites/:pieceId`.

Useful scripts (in `backend/`):

| Script | What it does |
| --- | --- |
| `npm run content:build` | Parse + validate EN/TR markdown into `content/build/*.json` |
| `npm run db:seed` | Load content, composers and `content/schedule.yaml` (which piece is Today) |
| `npm run fixtures` | Regenerate the app's bundled offline/preview data |
| `npm run images [-- --only <id>]` | Download originals (cached, git-ignored) and write HEIC `hero` / `thumb` (bundled + served) and `full` (served, for zoom) |
| `npm run images:widget` | Widget-only JPEGs (≤ 1100 px) from the heroes; run after `images` |
| `npm run emails:preview` | Render every email (EN/TR) to `design/emails/` |
| `npm run test-user -- <email> [--free]` | Create a verified test account (Premium unless `--free`); password goes to the git-ignored `backend/test-accounts.local.md` |

Railway: service root directory `backend/`; `railway.json` runs migrations before each deploy and health-checks `/health`.
Set `DATABASE_URL`, `DATABASE_URL_UNPOOLED`, `JWT_SECRET`, `RESEND_API_KEY`, `EMAIL_FROM`, `PUBLIC_API_URL`, `NODE_ENV=production` in the service variables. Custom domain: `api.dailyclassical.co`.

## iOS

```bash
brew install xcodegen
cd ios && xcodegen generate && open DailyClassical.xcodeproj
```

- Deployment target iOS 26, built with the iOS 27 SDK. System components only (TabView with a search tab, NavigationStack, sheets, `glassEffect`), so Liquid Glass, Reduce Transparency and Dynamic Type come from the system.
- Debug builds read bundled fixtures; set the scheme env var `DC_USE_API=1` to hit the local API.
- Language: Settings → Language (System / English / Türkçe). The choice sets `\.locale` at the root (UI strings from `Localizable.xcstrings`) and the API content locale.
