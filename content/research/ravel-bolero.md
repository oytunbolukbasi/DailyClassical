## 4. Facts in "The big picture" and the movement text

| Claim | Source URL | Status |
| --- | --- | --- |
| Commission from Ida Rubinstein; first plan to orchestrate Albéniz's *Iberia*; copyright held by Arbós; Ravel decided to write a new piece on the bolero | https://en.wikipedia.org/wiki/Bol%C3%A9ro | OK |
| Ravel to Samazeuilh at the piano: he would repeat the theme "a number of times without any development, gradually increasing the orchestra" | same | OK (paraphrased) |
| Premiere 22 November 1928, Paris Opéra; choreography Nijinska; scenario: a tavern in Spain, a dancer leaps onto the long table; Ravel preferred an open-air setting with a factory | same | OK |
| Snare-drum ostinato played 169 times; two 18-bar melodies; C major throughout; first melody diatonic, second with syncopation and flattened notes, first descends one octave, second two | same | OK |
| Order of instruments: flute, clarinet, bassoon, E-flat clarinet, oboe d'amore, trumpet and flute, tenor sax, soprano sax, horn + piccolos + celesta, oboe/cor anglais/clarinet, trombone, winds, first violins + winds… | same | OK |
| Piccolos double the horn in G and E (reinforcing overtones) | same | OK |
| Sudden change to E major near the end (rehearsal 18), back to C after eight bars; bass drum, cymbals and tam-tam enter only six bars from the end; trombone glissandi | same | OK |
| Two snare drums in the scoring ("one or more snare drums") | same (instrumentation) | OK. The guide says only that a second drum joins "later on"; the exact point was not checked |
| Ravel predicted orchestras would refuse to play it; it became his most famous work; he called it an experiment and said it had "no form, properly speaking, no development, no or almost no modulation" | same (Reception) | OK |
| Ravel preferred a steady tempo; at Coppola's January 1930 recording he stopped the conductor for speeding up near the end; Ravel's own 1930 recording lasts 15:50 | same (Tempo and duration) | OK |
