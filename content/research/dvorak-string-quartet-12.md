## 4. Facts in "The big picture" and the movement texts

| Claim | Source URL | Status |
| --- | --- | --- |
| Summer 1893 in Spillville, Iowa, a Czech immigrant community; Kovařík (his secretary) came from there; on vacation "since 3 June"; letter about being happy together, away from New York | https://en.wikipedia.org/wiki/String_Quartet_No._12_(Dvo%C5%99%C3%A1k) | OK |
| Sketched in three days, completed in thirteen more; "Thank God! I am content. It was fast."; written shortly after the *New World* Symphony | same | OK |
| "very melodious and straightforward … dear Papa Haydn kept appearing before my eyes" | same | OK |
| Pentatonic scale unifies the quartet; also used by Dvořák before America, in Slavonic-flavoured music | same | OK |
| II theme linked by some to a spiritual or a Kickapoo tune; no proof | same | OK |
| III: birdsong in the first violin (bars 21–24); thought to be a scarlet tanager, probably a red-eyed vireo (Ted Floyd, 2016); form A–B–A–B–A; B at half tempo in the minor, second time in triplets | same | OK |
| III: the theme starts in second violin and cello in octaves; B section in F minor | Japanese Wikipedia https://ja.wikipedia.org/wiki/弦楽四重奏曲第12番_(ドヴォルザーク) | SECONDARY |
| IV: rondo A–B–A–C–A–B–A; pentatonic main theme; "chugging" second violin and viola linked to trains (Dvořák's love of railways); C is a chorale | English Wikipedia (quartet) | OK |
| IV: main theme from bar 33 after a 24-bar introduction; B in A-flat major | Japanese Wikipedia | SECONDARY |
| I: viola introduces the purely pentatonic first theme over an unchanging F major chord for the first twelve bars; second theme in A major with melismatic ornaments; development ends in a fugato; cello solo bridge in the recapitulation | English Wikipedia (quartet) | OK |
| Metres: I 4/4, II 6/8, III 3/4, IV 2/4 | Japanese Wikipedia (and score excerpts there) | SECONDARY |
| II: theme in the first violin then the cello; pulsing accompaniment in second violin and viola; final statement in the cello over a thin accompaniment, alternately bowed and pizzicato | English Wikipedia (quartet) | OK |
| First private performance in Spillville with Dvořák on first violin; public premiere by the Kneisel Quartet, Boston, 1 Jan 1894 (not used in the guide) | same | – |
